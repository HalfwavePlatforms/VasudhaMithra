# Government Land Record Layout References (Specimens)

This directory contains specimen layout references for major state Bhulekh/LRMS portals used to calibrate synthetic document generator field positioning.

## References:
1. **Madhya Pradesh (MP Bhulekh - Khasra / Khatauni Formats)**:
   - URL: https://mpbhulekh.gov.in
   - Standard Fields: Survey No (सर्वे), Khasra No (खसरा), Khata No (खाता), Khatedar (खातेदार), Extent / Area (क्षेत्रफल), Village (ग्राम), Tehsil (तहसील), District (जिला).
2. **Karnataka (Bhoomi - RTC / Pahani Form 16)**:
   - URL: https://bhoomi.karnataka.gov.in
   - Standard Fields: Survey No (ಸರ್ವೆ ನಂ), Hissa No, Khatedar (ಖಾತೇದಾರ), Extent (ವಿಸ್ತೀರ್ಣ in Acre/Gunta), Soil Class, Mutation No (ನಮೂನೆ 12).
3. **Uttar Pradesh (UP Bhulekh - Khatauni Formats)**:
   - Standard Fields: Khatauni No, Fasli Year, Share / Extent, Land Type.
